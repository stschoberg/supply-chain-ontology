# CQ-002: Which products are single-sourced?

**Question:** Which products are supplied by exactly one supplier?

**Why it matters:** A single source is a supply chain vulnerability. In a DoD setting it connects directly to
industrial base and critical-minerals risk.

**Answered by:** [`CQ-002.rq`](CQ-002.rq)

**Reasoning required:** Yes, for supplier classification. The "exactly one" count is closed-world, so it is done in
SPARQL, not OWL. Under the open-world assumption, OWL cannot conclude that no other supplier exists.

**Status:** Implemented. Tested in `s01-single-source`.
